💧 How this extension calculates your estimate

Privacy: All tokenization and calculation happens locally, in your browser. Conversation text, token counts, and usage stats are never sent to AON. The optional offer search is separate: after one-time opt-in, supported shopping pages can request matches automatically using only product fields, cleaned shopping search keywords, or a generic request. Tracking data lives only in this browser's local extension storage until you clear it or uninstall the extension.

Optional automatic AON product matches

On Amazon.in, Amazon.com, and Flipkart, AquaTrace reads a bounded product snapshot locally. Product context is used first; when no product context is available, it cleans the Amazon k or Flipkart q search value before using it, with a generic request as the final fallback. After you enable Show sponsored product suggestions while I shop on Amazon and Flipkart once, it sends the displayed product title, category, price, and currency—or cleaned search keywords, or the generic text Show me relevant offers—to AON over HTTPS. It does not send the page URL, page text, seller, account data, cookies, AI conversations, or local tracking history. Returned offers are clearly labeled sponsored results, and choosing an offer opens its HTTPS destination in a new tab. Uncheck the setting in the popup to hide the in-page offer bar and stop AON requests. In-flight requests are aborted; this cannot retract data already sent before you turned the switch off.

Automatic offers are off by default. Installation or the first upgrade to the automatic-offer feature opens a separate onboarding page with one unchecked opt-in checkbox. The older popup-only preference is reset for this broader automatic feature. Empty results are retried with brand/model text, a category word, and finally the generic request. Page changes are debounced for about 800 milliseconds. The bar shows up to three sponsored cards and can be collapsed or dismissed for the tab. Dismissal and the last non-empty offers are kept only in extension session storage; errors and empty responses hide the bar without erasing that session cache.

Identical offer queries (including empty results) are cached in chrome.storage.session for ten minutes. AquaTrace makes at most 50 AON query attempts per UTC day per browser profile, including fallback attempts and failures. Only the day and counter persist locally across browser restarts. AON's separate placement-wide cap is 1,000 offers per day; its small catalog, availability, or that cap can leave the bar empty. Requests time out after eight seconds. HTTPS requests omit credentials and referrers; AON still sees ordinary connection metadata such as an IP address. Offer images load without cross-origin credentials or referrers and may appear as placeholders if the image server does not permit that. Clicking a sponsored card navigates directly to its supplied HTTPS tracking link; the destination's own privacy policy then applies. No click-report API is called.

0. Each site is tracked independently

ChatGPT, Claude, Gemini, and DeepSeek each get their own separate counter and their own model dropdown. Tokens from one site are never combined with or multiplied by a model assumption picked for a different site -- each site's numbers are calculated only from that site's own tokens and that site's own selected model.

Note: As of version 1.1.0, we've added full support for DeepSeek AI, including both DeepSeek V3 and the reasoning-focused DeepSeek R1 model. These models are automatically detected when you use chat.deepseek.com.

1. Counting tokens

We use gpt-tokenizer, a JavaScript implementation of OpenAI's real tokenizer. The bundled tokenizer uses the same byte-pair-encoding scheme as GPT-4o and is also used as a proxy for the GPT-5 profile until a GPT-5 tokenizer is available. It counts tokens in whatever text is typed into the chat box and whatever text gets added to the page in response.

For GPT-4o Mini and GPT-4o, this is the model's actual tokenizer, so counts are exact. The GPT-5 profile currently reuses the bundled GPT-4o tokenizer until a GPT-5 tokenizer is available. For Claude and Gemini models, neither Anthropic nor Google publish an installable tokenizer library, so we reuse the OpenAI tokenizer as a stand-in. Token boundaries will differ slightly from what those models really use internally, but total counts land in a similar range for ordinary English text.

2. Detecting when a response finished

We watch the page for DOM changes after you submit a prompt. Once the page stays quiet for 1.5 seconds, we treat the response as finished and tokenize whatever text was added during that time.

Caveat: Long reasoning responses (like those from o1 or DeepSeek R1) that pause for more than 1.5s mid-generation may get split into two tokenize events, which can occasionally result in undercounting.

Special note on DeepSeek models: DeepSeek V3 is a Mixture-of-Experts (MoE) architecture with 671B total parameters but only 37B active per token, making it relatively efficient. DeepSeek R1 is designed for chain-of-thought reasoning and typically generates significantly more output tokens (including internal reasoning steps), which results in higher per-query energy consumption — though the per-token rate itself is comparable to other large reasoning models.

4. Turning energy into water

Data centers report a Water Usage Effectiveness (WUE) figure: liters of water per kWh of energy used. Unlike our earlier version, we no longer use one shared range for every model -- each model uses the WUE range of the company that actually hosts it, since AWS, Microsoft Azure, and Google run meaningfully different infrastructure.

5. Turning energy into CO2e

Grid carbon intensity varies significantly by region, so this uses a per-company/region figure rather than one flat global number:

  • AWS, Microsoft Azure, Google: 445 g CO2 per kWh (IEA global average, 2024)
  • China (DeepSeek): 555 g CO2 per kWh -- a rough midpoint of IEA figures showing China's grid at approximately 565 g/kWh in 2024, forecast to decline toward 505 g/kWh by 2026. China's grid is meaningfully more carbon-intensive than the global average, which is a real factor in why DeepSeek's CO2e estimate runs higher, separate from its energy-per-token efficiency

6. Exporting your data

The extension includes an export feature to download usage data as a CSV. It contains: Site, Model, Prompts, Input Tokens, Output Tokens, Water (mL) Low/High, Energy (Wh), and CO₂ (g). The Copy Summary action copies the selected site's prompt and response totals to the clipboard. The popup also keeps up to 100 local conversation summaries and shows a seven-day token trend; conversation text is never stored.

Bottom line

Every number in this extension is a modeled estimate built from public research, not a measurement of your specific request. Treat it as illustrative — a way to build intuition for how usage scales with conversation length and model size — rather than a precise figure.
