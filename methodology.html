💧 How this extension calculates your estimate

Privacy: All tokenization and calculation happens locally, in your browser. No conversation text, token counts, or usage stats are ever sent anywhere. Data lives only in this browser's local extension storage until you clear it or uninstall the extension.

0. Each site is tracked independently

ChatGPT, Claude, and Gemini each get their own separate counter and their own model dropdown. Tokens from one site are never combined with or multiplied by a model assumption picked for a different site -- each site's numbers are calculated only from that site's own tokens and that site's own selected model.

1. Counting tokens

We use gpt-tokenizer, a JavaScript implementation of OpenAI's real tokenizer (the same byte-pair-encoding scheme used by GPT-4o and GPT-5), to count tokens in whatever text is typed into the chat box and whatever text gets added to the page in response.

For GPT-4o Mini and GPT-5, this is the model's actual tokenizer, so counts are exact. For Claude and Gemini models, neither Anthropic nor Google publish an installable tokenizer library, so we reuse the OpenAI tokenizer as a stand-in. Token boundaries will differ slightly from what those models really use internally, but total counts land in a similar range for ordinary English text.

2. Detecting when a response finished

We watch the page for DOM changes after you submit a prompt. Once the page stays quiet for 1.5 seconds, we treat the response as finished and tokenize whatever text was added during that time.

4. Turning energy into water

Data centers report a Water Usage Effectiveness (WUE) figure: liters of water per kWh of energy used. Unlike our earlier version, we no longer use one shared range for every model -- each model uses the WUE range of the company that actually hosts it, since AWS, Microsoft Azure, and Google run meaningfully different infrastructure.

Hosting companyUsed byWUE range (L/kWh)Basis
Amazon / AWS Claude Sonnet, Claude Opus 0.15 – 1.8 AWS's own efficient-case claim, up to the broader industry average as a conservative high end

Google Gemini Flash, Gemini Pro 0.50 – 1.2 Third-party estimate -- Google does not publish an official fleet-wide WUE figure

Important caveat on Anthropic and Claude specifically: Anthropic's Claude models run on multiple cloud providers, not exclusively AWS. We use AWS's figures here as a reasonable primary estimate, but this is a simplification, not a confirmed hosting detail.

mL of water = Wh of energy × WUE (L/kWh) — shown as a range using the relevant company's WUE.

5. Optional CO2e estimate

We also show a rough CO2-equivalent figure, using the IEA's 2024 global average power-sector carbon intensity of 445 grams CO2 per kWh. This is a global average — your actual grid's carbon intensity could be several times higher or lower depending on your region's energy mix.

Bottom line

Every number in this extension is a modeled estimate built from public research, not a measurement of your specific request. Treat it as illustrative — a way to build intuition for how usage scales with conversation length and model size — rather than a precise figure.
