Privacy Policy — AquaTrace

Last updated: July 2026

Summary

This extension does not collect, transmit, sell, or share any user data with anyone, including the developer. Everything it does happens locally in your browser.

What the extension does

When you send a message on ChatGPT, Claude, or Gemini, this extension reads the text of your prompt and the AI's response directly from the webpage in order to estimate a token count, and calculates an estimated water/energy/CO2 footprint from that count. This processing happens entirely within your browser.

What data is stored, and where

The extension stores only aggregate numbers -- prompt counts and token counts per site -- using Chrome's built-in local extension storage (chrome.storage.local). This data:

  • Never leaves your device
  • Is never sent to any server, including any server operated by the developer
  • Is not shared with any third party
  • Does not include the actual text of your conversations -- only token counts
  • Persists only until you click "Reset" in the extension, or uninstall it

Permissions this extension uses, and why

  • storage -- to save your running token counts locally, so they persist between browser sessions.
  • activeTab -- to detect which supported AI site your current tab is on, only at the moment you open the extension's popup.
  • Host access to chatgpt.com, chat.openai.com, claude.ai, and gemini.google.com -- to read prompt/response text on those specific pages in order to count tokens. No other websites are accessed.

Third parties

This extension does not use any analytics, tracking, or advertising services. It makes no network requests of its own.
