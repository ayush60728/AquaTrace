Privacy Policy — AquaTrace

Last updated: October 2026

Summary

AquaTrace keeps footprint tracking local. An optional shopping-product search is separate and sends only a small allowlisted product snapshot, cleaned shopping search keywords, or a generic request after you enable automatic matches once. With the checkbox off, no AON requests are made, including from the popup.

What the extension does

When you send a message on ChatGPT, Claude, Gemini, or DeepSeek, this extension reads the text of your prompt and the AI's response directly from the webpage in order to estimate a token count, and calculates an estimated water/energy/CO2 footprint from that count. This processing happens entirely within your browser.

What data is stored, and where

For AI tracking, the extension stores aggregate numbers -- prompt counts and token counts per site -- plus up to 100 local conversation summaries containing timestamps, site, model, and token counts. It uses Chrome's built-in local extension storage (chrome.storage.local). This data:

  • Never leaves your device for footprint tracking
  • Is not sent to the developer or used for analytics
  • The local tracking data is not shared with any third party
  • Does not include the actual text of your conversations -- only token counts
  • Persists only until you click "Reset" in the extension, or uninstall it

The shopping opt-in and a daily request counter are also saved locally. Offer queries and responses are cached in extension session storage for ten minutes, never in Chrome sync or a shopping site's storage. The quota allows up to 50 query attempts per UTC day per browser profile, including empty results, errors and fallbacks. Neither this counter nor AI history is included in AON requests.

Permissions this extension uses, and why

  • storage -- to save your running token counts locally, so they persist between browser sessions.
  • activeTab -- to detect which supported AI site your current tab is on, only at the moment you open the extension's popup.
  • Host access to chatgpt.com, chat.openai.com, claude.ai, gemini.google.com, and chat.deepseek.com -- to read prompt/response text on those specific pages in order to count tokens. No other pages are read for tracking.
  • Host access to Amazon and Flipkart pages -- to read product title, category, displayed price, and currency locally, or cleaned search keywords when product context is unavailable, for the opt-in in-page offer bar and popup preview.
  • Host access to api.aon.pro -- to request optional sponsored product matches automatically after you enable the checkbox.

Third parties

AquaTrace does not use analytics. After you enable automatic matches once, only the displayed product title, category, price, and currency are sent to AON (Agent Offer Network) to return sponsored matches. Without a product snapshot, only cleaned Amazon k or Flipkart q search keywords, or the text Show me relevant offers, are sent instead. Popup refreshes require the same checkbox and use the same allowlist. The product URL, seller, page text, cookies, account data, AI chat text, token counts, local history, and tab metadata are not included. Normal HTTPS connection metadata, such as an IP address, may still be visible to AON; AquaTrace does not add a user ID, cookie, or account identifier. Offer links are provided by AON, and AquaTrace may earn a commission if you choose one. Images are requested without cross-origin credentials or referrers. Clicking an offer opens its direct tracking link; the destination's own privacy policy and normal browser navigation behavior then apply.

Automatic offers are off by default and can be turned off using the popup checkbox. The first upgrade to this automatic-offer feature resets the earlier popup-only opt-in and opens a one-time onboarding page to ask for this broader automatic feature. Opt-out aborts pending requests but cannot retract data already sent. Dismissal and the last non-empty offers are kept per tab in extension session storage and are removed when the tab or browser session ends.
