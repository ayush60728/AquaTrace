Privacy Policy — AquaTrace

Last updated: October 21, 2026

Summary

AquaTrace keeps footprint tracking local. An optional shopping-product search is separate and sends only a small allowlisted product snapshot, cleaned shopping search keywords, or a generic request from the AquaTrace shopping experience after you enable suggestions once. With the checkbox off, no AON requests are made.

This page is the public privacy policy for the AquaTrace Chrome extension. It explains the data the extension accesses, what stays on your device, what is sent to AON, and how sponsored offer links work.

What the extension does

When you send a message on ChatGPT, Claude, Gemini, or DeepSeek, this extension reads the text of your prompt and the AI's response directly from the webpage in order to estimate a token count, and calculates an estimated water/energy/CO2 footprint from that count. This processing happens entirely within your browser.

What data is stored, and where

For AI tracking, the extension stores aggregate numbers -- prompt counts and token counts per site -- plus up to 100 local conversation summaries containing timestamps, site, model, and token counts. It uses Chrome's built-in local extension storage (chrome.storage.local). This data:

  • Never leaves your device for footprint tracking
  • Is not sent to the developer or used for analytics
  • The local tracking data is not shared with any third party
  • Does not include the actual text of your conversations -- only token counts
  • Persists only until you click "Reset" in the extension, or uninstall it

The shopping opt-in and a daily request counter are also saved locally. Offer queries and responses are cached in extension session storage for ten minutes, never in Chrome sync or a shopping site's storage. The quota allows up to 50 query attempts per UTC day per browser profile, including empty results, errors and fallbacks. Neither this counter nor AI history is included in AON requests.

How data is used and shared

AquaTrace uses data only to provide its two disclosed user-facing features: local AI-footprint estimates and optional sponsored shopping suggestions. It does not sell user data, use it for personalized or retargeted advertising, or use it to build an unrelated browsing profile. AquaTrace does not allow people to read individual user data except where necessary for security, legal compliance, or support that the user specifically requests.

The shopping fields listed below are shared with AON only when the user has enabled sponsored suggestions. This transfer is necessary to match and return the sponsored offers displayed by the extension. AON may share a query with authorized offer partners to provide those results; those partners' own privacy policies apply. No other third party receives the extension's local AI history or conversation text.

Permissions this extension uses, and why

  • storage -- to save your running token counts locally, so they persist between browser sessions.
  • activeTab -- to detect which supported AI site your current tab is on, only at the moment you open the extension's popup.
  • Host access to chatgpt.com, chat.openai.com, claude.ai, gemini.google.com, and chat.deepseek.com -- to read prompt/response text on those specific pages in order to count tokens. No other pages are read for tracking.
  • Host access to Amazon and Flipkart pages -- to read product title, category, displayed price, and currency locally, or cleaned search keywords when product context is unavailable, for the opt-in sponsored suggestions and product preview.
  • Host access to api.aon.pro -- to request optional sponsored product matches after you enable the checkbox.

Third parties

AquaTrace does not use analytics. After you enable sponsored suggestions once, only the displayed product title, category, price, and currency are sent to AON (Agent Offer Network) to return sponsored matches. Without a product snapshot, only cleaned Amazon k or Flipkart q search keywords, or the text Show me relevant offers, are sent instead. Automatic refreshes and popup requests require the same checkbox and use the same allowlist. The product URL, seller, page text, cookies, account data, AI chat text, token counts, local history, and tab metadata are not included. Normal HTTPS connection metadata, such as an IP address, may still be visible to AON; AquaTrace does not add a user ID, cookie, or account identifier. Offer links are provided by AON, and AquaTrace may earn a commission if you choose one. Images are requested without cross-origin credentials or referrers. Clicking an offer opens its direct tracking link; the destination's own privacy policy and normal browser navigation behavior then apply.

Security and retention

AquaTrace sends optional shopping requests over HTTPS with credentials and referrers omitted. The extension does not send authentication cookies or embed a user API key. Local data is retained in Chrome extension storage until you reset it, clear extension data, or uninstall AquaTrace. Temporary offer results and query-cache entries are held in Chrome session storage and are removed when the browser session ends.

AON's retention and processing are governed by the AON Privacy Policy. Please consult that policy for the current retention period, operational logging, analytics, click-attribution, and partner-processing details.

Chrome Web Store Limited Use

AquaTrace's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Chrome API data is used only for the user-facing features described on this page and in the Chrome Web Store listing. Transfers are limited to what is necessary to provide those features, protect security, or comply with law.

AON's handling is described in its AON Privacy Policy. AON states that it may record the submitted product-related query and request metadata for matching, routing, abuse prevention, and service operation. Its current policy states that the primary request-journal copy is scheduled for deletion after a default seven-day window, while an analytics-warehouse copy is not covered by that purge; operational logs are typically retained for no longer than 30 days, and click-attribution records are retained for settlement. AON may forward a query to authorized offer partners, whose own privacy policies apply after you follow an offer.

Sponsored suggestions are off by default and can be turned off using the popup checkbox. The first upgrade to this feature resets the earlier opt-in and opens a one-time onboarding page to ask for consent. Opt-out aborts pending requests but cannot retract data already sent. The last non-empty offers are kept in extension session storage and are removed when the browser session ends.
